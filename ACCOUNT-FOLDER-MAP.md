## Rules

- Use the folder matching the platform being operated.
- Keep platform-specific workflows beside that platform's `account.yaml`.
- Keep credentials, tokens, cookies, recovery codes, and private identifiers
  outside this repository.
- Update both this map and `ACCOUNT-MATRIX.yaml` when adding a new identity.
- Prefer verifying and activating existing folders over creating new ones.
- Expand each live account to the
  [`ACCOUNT-PROFILE-STANDARD.md`](./ACCOUNT-PROFILE-STANDARD.md) fields when
  you touch it (URL/handle, status, bio, pillars, CTA, venture, frequency).
- Copy verification and metrics templates from `templates/accounts/` only for
  accounts you are actively launching.
